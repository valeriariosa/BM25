# E-commerce de ropa + BM25
POC académico con 10 productos, buscador BM25, carrito y checkout simulado.

## Render
Crear **Web Service** con Runtime **Node** (NO Docker).
Build Command: `npm install`
Start Command: `npm start`
Root Directory: vacío
Plan: Free

## BM25
El backend calcula BM25 sobre nombre + categoría + descripción de cada producto y devuelve el ranking de relevancia para la consulta.
